# orb-luz

Bola de luz da home da olahello. Este repositório só serve o script para o Webflow pelo jsDelivr. O protótipo, as medidas e a documentação ficam na base da olahello.

- `orb.js`, a bola em WebGL. Precisa de GSAP 3 e ScrollTrigger na página.
- `matcap-olahello.webp` e `matcap-olahello-chao.webp`, os discos da reserva sem WebGL.

Cada versão sai por tag, por exemplo `https://cdn.jsdelivr.net/gh/olahello/orb-luz@v0.1.0/orb.js`.

Código da olahello. Todos os direitos reservados.
